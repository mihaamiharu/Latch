# Latch agent icon

Generated with the built-in image generation tool. The mark combines an agent's two eyes, interlocking latch brackets, and a browser-tab shoulder.

## Final prompt

Use case: logo-brand. Asset type: finished app icon for Latch, a browser extension that lets an autonomous QA coding agent attach to an existing signed-in browser session. Create one exceptionally strong, distinctive, minimal brand mark that immediately conveys an AGENT plus a LATCH/CONNECTION. The central symbol is a compact geometric agent face: exactly two large clear ivory horizontal rounded eye slots in a dark negative-space face. Two chunky interlocking rounded bracket pieces form the agent head's frame: the left/top bracket bright mint and the right/bottom bracket warm coral-orange, visibly hooked together at one decisive join. Integrate a single small browser-tab shoulder into the top frame, so it reads as an agent latched into a browser, not a folder, not a chain alone, not a padlock. The eyes are the dominant recognition feature. No mouth, no antenna, no humanoid body, no decorative circuit lines, no sparkles, no arrows. Keep the geometry extremely simple, with broad filled forms and large internal negative space, maximum four main shape elements besides the background. Place the mark centrally on a solid deep charcoal-navy rounded-square tile. Palette: charcoal-navy #11252D, vivid mint #56E3B0, warm coral #FF865C, ivory #F8FAF5. Precise flat 2D graphic, crisp edges, no gradients, no texture, no shading, no 3D, no shadows. Optical balance, confident generous proportions, recognizable as a 16px Chrome toolbar icon and polished at 128px. Single icon fills the image with about 8 percent breathing room around the mark inside the tile. No lettering, no wordmark, no text, no presentation sheet, no mockup, no border around canvas. Transparent outside the rounded-square tile only, opaque tile and glyph.
