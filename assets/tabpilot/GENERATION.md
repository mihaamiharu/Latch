# TabPilot icon concept

Generated with the built-in image generation tool. The product name is a proposal; the extension display name and stable identifiers remain unchanged.

## Final prompt

Use case: logo-brand. Asset type: a single finished square Chrome extension app icon for a developer QA tool, proposed name TabPilot. Primary request: create an exceptionally simple, distinctive professional icon communicating an existing browser tab being steered by an agent. Subject: one bold mint browser-tab outline with a broad white navigation needle pointing diagonally upper right inside it, on a solid very dark navy rounded-square badge. Integrate the tab shoulder naturally into its upper edge; use just one tab and one needle, no extra symbols. Style: precise flat geometric logo, smooth rounded heavy forms, crisp edges, generous clear negative space, high contrast, beautiful optical balance. Composition: centered single icon only, large mark occupying most of the badge, generous safe edge margins. Palette: navy #102B36, mint #56E3B0, white. No text or letters, no wordmark, no grid or presentation sheet, no mockup, no 3D, no gradient, no shadow, no texture, no thin strokes, no decorative sparkles. Designed to remain recognizable as a 16px toolbar icon and a 128px extension icon. Render at high square resolution. Only the area outside the rounded-square badge is genuinely transparent; preserve opaque badge and logo.
