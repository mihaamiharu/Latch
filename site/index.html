Your signed-in Chrome, built for CLI QA.

Built for daily QA from the terminal

          

            When you run Claude Code, Codex, or Antigravity from the CLI, you don't have an IDE browser—and isolated headless browsers can't reach your SSO-gated work tabs. Latch gives CLI agents safe, auditable access to your real Chrome.
          


          

            

              
Works across CLI agent subscriptions

              

                One flat latch CLI and a 3 KB skill prompt—no MCP tool bloat. Hop between Claude Code, Codex, Antigravity, and Cursor in the terminal using the exact same browser commands.
              

            

            

              
Single-tab safety in your work Chrome

              

                Attach one signed-in tab with latch connect <tabId> and per-session locks (-s). Your email, Slack, and other tabs stay isolated and untouched on disconnect.
              

            

            

              
Zero repo clutter & background focus

              

                Active sessions and large ARIA snapshots spill to OS app data—never dirtying git status. Background focus emulation lets agents explore without stealing your cursor.
              

            

            

              
Exploratory QA filmstrips & triage

              

                Pass --record to capture before/after PNGs, ARIA/DOM locator candidates with ambiguity warnings, and checkpoints that never fabricate assertions—reviewed locally at 127.0.0.1.
              

            

          


          

            
Where Latch fits in a QA stack

            

              Latch is built on playwright-core to complement the rest of your tooling, not replace it. Use Playwright directly for CI test suites and headless runs, OpenCode Browse or Chrome DevTools MCP for general MCP browsing and browser profiling, and Latch for exploratory QA from terminal CLI coding agents in your real signed-in Chrome.

Tab-scoped access, local-first by design

          

            Your agent runs short CLI commands over a local bridge. Latch attaches Chrome's debugger only to the single tab you explicitly open or connect—never persistent content scripts or full-profile access.
          


          

          

            

              
Keep your logins and open tabs

              
Attach directly to corporate SSO, staging apps, and authenticated sessions already open in Chrome. Disconnecting leaves every tab intact.

            

            

              
Zero external binaries to babysit

              
Playwright Core runs inside the native messaging host over a private loopback CDP relay. No browser downloads or ffmpeg required.

            

            

              
Clean repositories and smart defaults

              
Active workspace sessions bind under your local app data directory, never writing dotfiles into your codebase. Profile and session flags default automatically.

            

            

              
Built for modern AI toolchains

              
Works out of the box with Antigravity plugins, Claude Code skills, Codex, and Cursor using a compact 3 KB skill prompt and flat CLI output.

            

          

        

      


      

        

          
Exploration Library for QA review

          

            Pass --record or --objective on open or connect to capture before/after PNG filmstrips, ARIA snapshots, and locator candidates—so you can review observed behavior locally before deciding what becomes a bug report or a Playwright test.

Local-first security guarantees

            

              Latch never installs persistent website content scripts or telemetry. Known credentials, tokens, cookies, and internal CDP endpoints are redacted automatically, and uninstalling leaves your configuration and saved library intact until you delete them.
