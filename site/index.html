Install in four steps

          

            Requires Node.js 22 or newer and Google Chrome 125 or newer. External Playwright downloads and ffmpeg are never needed.

Step 1. Install the bridge and register the native host

              
Install @mihaamiharu/latch globally and register com.latch.bridge plus agent integrations.

              

                

                
              

            


            

              
Step 2. Load the Chrome extension

              

                Open chrome://extensions in Chrome, turn on Developer mode, click Load unpacked, and select the Extension path printed by Step 1. Confirm the ID is dlkpkeiejlgggeoibejpoajedoelfcli.
              

            


            

              
Step 3. Pair Chrome and verify connectivity

              
With Chrome open, auto-discover the running extension instance and check bridge health.

              

                
latch pair
latch doctor

                
              

            


            

              
Step 4. Verify your agent plugins

              
Check that Antigravity, Claude Code, Codex, and Cursor links are active, then ask your agent to inspect a tab.

              

                
latch agents status

                
              

            

          

        

      


      

        

          
How Latch connects without leaking credentials

          

            Your agent runs short CLI commands against a local socket. Everything sensitive stays inside Chrome and the loopback native host.
          


          

          

            

              
Keep your logins and open tabs

              
Attach directly to corporate SSO, staging apps, and authenticated sessions already open in Chrome. Disconnecting leaves every tab intact.

            

            

              
Zero external binaries to babysit

              
Playwright Core runs inside the native messaging host over a private loopback CDP relay. No browser downloads or ffmpeg required.

            

            

              
Clean repositories and smart defaults

              
Active workspace sessions bind under your local app data directory, never writing dotfiles into your codebase. Profile and session flags default automatically.

            

            

              
Built for modern AI toolchains

              
Works out of the box with Antigravity plugins, Claude Code skills, Codex, and Cursor using a compact 3 KB skill prompt and flat CLI output.

            

          

        

      


      

        

          
Visual filmstrips and one-click storage control

          

            Pass --record or --objective on open or connect to capture before and after PNG screenshots, ARIA snapshots, and locator candidates for local QA review.

Local-first security guarantees

            

              Latch never installs persistent website content scripts or telemetry. Known credentials, tokens, cookies, and internal CDP endpoints are redacted automatically, and uninstalling leaves your configuration and saved library intact until you delete them.
